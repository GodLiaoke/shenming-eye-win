# Myrader Val Windows 修复交付（2026-10-15）

## 修复内容

- 43 网关当前返回两类地址：
  - `room_url`：客户端私有地址，必须带 `?access=<token>`。
  - `radar_url`：浏览器/共享雷达短链接，形如 `/r/<room>`，不带令牌是正常设计；访问后由网关建立房间会话并跳转雷达页。
- Windows 客户端此前把 `radar_url` 也按“必须带令牌”的私有地址校验，因此服务端返回合法短链接时误报“房间令牌缺失”。
- 本次仅放宽 `radar_url` 校验：允许无查询参数的短链接，同时继续严格校验来源、路径和非法查询参数；`room_url` 仍强制要求非空 `access` 令牌。
- 未修改 114/43/140 服务器。
