# 神明之眼 1.0 · Windows 小白使用教程

> 这个版本**不需要卡密**，打开就能用。看完这一页就能自己跑起来，出问题也能自己把「抓包文件」找出来发给客服。

---

## 0. 三十秒版（懒人版）

1. 把 zip 解压到一个**固定文件夹**（别放桌面临时目录，别放 C 盘以外的网盘同步目录）。
2. **右键 `Shenming-Eye.exe` → 以管理员身份运行**（必须，否则抓包驱动起不来）。
3. 窗口左上角状态变绿、显示「实时接收已启动」＝成功。
4. 开游戏（端游）或按第 4 节连手机。
5. 想看雷达：点侧栏「在浏览器打开雷达」。
6. 要抓包：点侧栏「打开抓包文件夹」，里面的 `proxy-*.pcap` 就是。

---

## 1. 电脑要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 1809 以上 / Windows 11，**64 位** |
| 权限 | **管理员**（程序要加载 WinDivert 抓包驱动） |
| 运行库 | WebView2 Runtime（Win11 自带；Win10 打不开界面时安装微软官方 Evergreen 版） |
| 端口 | `2025`（手机代理）、`18080`（本机雷达页）不能被别的程序占用 |
| 网络 | 端游模式要能正常上网；手机模式电脑与手机要在**同一个 Wi‑Fi / 热点** |

> 程序是**单文件**：`Shenming-Eye.exe` 里已经内嵌了抓包驱动（WinDivert）和本机雷达引擎，解压只需要这一个 exe。

---

## 2. 第一次运行

1. 解压 zip，得到 `Shenming-Eye.exe` 和本教程。
2. **右键 → 以管理员身份运行**。
   - 没弹 UAC？说明你当前账户不是管理员，换账户或右键「属性 → 兼容性 → 以管理员身份运行此程序」。
3. 可能出现 Windows 防火墙提示：**允许专用网络**（局域网手机要连电脑，必须放行）。
4. 侧栏状态：
   - 🟡「正在启动本机引擎…」＝正常，等 3–10 秒；
   - 🟢「实时接收已启动」＝好了；
   - 🔴 红字「采集驱动未启动」＝看第 7 节排障。
5. 如果杀软弹窗拦截 `WinDivert64.sys`：选**允许/信任**。这是抓包驱动，不是病毒；被拦了就抓不到游戏流量。

---

## 3. 端游模式（电脑自己玩游戏）

1. 先启动本程序（保持窗口开着，可以最小化，别退出）。
2. 再启动游戏、进一局。
3. 侧栏「接收引擎」卡片的圆点会变绿、`UDP 转发` 计数会动。
4. 点「在浏览器打开雷达」，浏览器里就是实时雷达（也可以直接看程序内的雷达窗格）。

> 顺序很重要：**先开本程序，再进游戏**。反过来的话，这一局拿不到名单（英雄/阵营），只能看到坐标。

---

## 4. 手机模式（手机上玩游戏，电脑看雷达）

### 4.1 同一个 Wi‑Fi（推荐）

1. 电脑和手机连**同一个路由器 Wi‑Fi**。
2. 侧栏「手机游戏节点」会显示 `电脑IPv4:2025` 和一个二维码。
3. 手机装 **Shadowrocket（小火箭）** → 首页右上角**扫码** → 扫这个二维码。
4. 回到小火箭首页：
   - 点一下刚加的那个节点（右侧打勾）；
   - 打开顶部**总开关**连上；
   - **全局路由 → 代理（Proxy）**（默认「配置」会把游戏流量漏掉）。
5. 手机上开游戏，电脑上看雷达。

### 4.2 电脑开热点（没路由器 / 不同网段）

1. Windows 设置 → 网络 → 移动热点 → 打开，让手机连这个热点。
2. 回到本程序点侧栏「重新连接」，二维码地址会变成热点网段（一般是 `192.168.137.x`）。
3. 其余步骤同 4.1。

### 4.3 手动填节点（扫码失败时）

小火箭右上角 `+` → 类型 **SOCKS5**（不是 HTTP）→

| 字段 | 值 |
|---|---|
| 服务器 | `127.0.0.1`（手机自己也跑程序时）或 `电脑IP`（电脑跑程序时） |
| 端口 | `2025` |
| 用户名 | `phoenix-local` |
| 密码 | 侧栏节点地址里 `socks5://phoenix-local:密码@IP:2025` 中间那段 |

保存后同样：选中 → 开总开关 → 全局路由＝代理。

## 5. 抓包（重点，出问题就靠它）

### 5.1 它自己就在录，不用你点“开始”

引擎启动后，只要有游戏流量经过，就会**自动**把原始数据包写成 PCAP 文件：

```
%LOCALAPPDATA%\Phoenix\local-engine\record\proxy-<时间戳>-<进程号>-<序号>.pcap
```

- 每 **30 分钟**切一个新文件，最多保留 **5 个**（旧文件自动删除）；
- 侧栏有按钮：**「打开抓包文件夹」**（直接弹资源管理器）、**「复制文件夹路径」**；
- 想手动找：文件资源管理器地址栏粘贴 `%LOCALAPPDATA%\Phoenix\local-engine\record` 回车。

### 5.2 怎么发给我 / 发客服

1. 侧栏点「打开抓包文件夹」。
2. 只发**最新那个** `proxy-....pcap` 就够（一局一个）。
3. 压缩成 zip（右键 → 压缩为 ZIP），把 zip 发过来。
4. 附一句：**哪一局、什么时间、什么现象**（例如「14:32 那局，雷达上没英雄」）。

> 文件里有你这一局的原始网络数据（含 IP、UDP 载荷），**不含卡密**（本版本也没有卡密）。只发给你信任的人。

### 5.3 用 Wireshark 自己看

1. 装 Wireshark（免费）；2. 打开 `proxy-*.pcap`；3. 过滤器输入 `udp` 或 `udp.port == 8013`。

| 区域 | 含义 |
|---|---|
| 接收引擎 | 圆点绿＝在收；琥珀＝在启动；红＝驱动/端口有问题 |

| 抓包（反馈/取证） | 抓包目录 + 一键打开 |
| 底部 | 版本号、构建号 |

## 7. 常见问题

**① 红字「采集驱动未启动」**
- 没用管理员运行 → 关掉，右键以管理员身份重开；
- 杀软拦了 `WinDivert64.sys` → 加信任；
- 系统禁用了 unsigned driver 相关策略（少见）→ 换一台机器试。

**② 状态一直是「正在启动本机引擎…」**
- 端口被占用：任务管理器结束残留的 `Shenming-Eye.exe` / `codev-net.exe` 后重启；
- 数据目录被安全软件锁住：看 `%LOCALAPPDATA%\Phoenix\logs\app.log` 最后几行。

**③ 手机连上了但游戏上不去**
- 小火箭「全局路由」要选**代理**；
- 节点类型必须是 **SOCKS5**（填 HTTP 一定失败）；
- 手机和电脑不在一个网段 → 改用电脑热点（4.2）。

**④ 雷达有坐标但没有英雄/名字**
- 必须**进入对局前**就开着本程序（名单是开局那一刻抓到的）；
- 中途才开 → 这一局只有坐标，下一局正常。

**⑤ 浏览器打开雷达是白屏**
- `18080` 被占用或防火墙拦了本机回环：关掉占用程序再「重新连接」；
- 装了广告拦截/杀软网页防护 → 临时关掉。

**⑥ 想彻底重置**
- 关掉程序，删除 `%LOCALAPPDATA%\Phoenix` 整个文件夹（抓包文件也一起没了，先备份）。

---

## 8. 卸载

1. 关掉程序；
2. 删除 exe 所在文件夹；
3. 删除 `%LOCALAPPDATA%\Phoenix`（配置、日志、抓包）。
